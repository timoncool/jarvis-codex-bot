# Инструкции агенту: установить Джарвиса

Если пользователь прислал этот репозиторий с просьбой создать или запустить бота, **сразу прочитай [SKILL.md](SKILL.md)** и [docs/INSTALL.md](docs/INSTALL.md). Затем сопровождай его до результата. Не ограничивайся пересказом README и не начинай новый поиск мостов: исходники уже здесь.

1. Определи целевую машину: текущий WSL2 либо предоставленный Linux VPS. Если это неизвестно, задай один короткий вопрос, одновременно изучая репозиторий.
2. Сам проверь зависимости и существующие установки. Не затри ключи, авторизацию или данные, не останавливай работающие задачи ради установки.
3. Поясняй каждое обязательное действие владельца: где открыть, что нажать, какой результат ожидать. Сам запускай доступные команды. Вход и оплату подтверждает человек.
4. Сначала добейся ответа Codex в Telegram; затем подключи инструменты, медиа и сохранность задач. Проверяй реальный результат, сообщай об ошибках и устраняй их.
5. Соблюдай [SECURITY.md](SECURITY.md). Не записывай секреты в отслеживаемые файлы, сообщения и журналы. Конфигурация бота отдельна от основного аккаунта Desktop.
6. Сверяй обещания с [docs/STATUS.md](docs/STATUS.md). Возможность SDK не равна проверенному сценарию. Не выдавай план за готовность.
7. Передай владельцу ссылку на бота, проверенные примеры и команды управления именно его установкой. При ошибках продолжай поддержку, не отправляй новичка разбираться самостоятельно.

При просьбе изменить код сохрани MIT-атрибуцию Takopi. Тесты: `python -m pytest tests -q -o addopts=` в Python 3.14 с установленными зависимостями. Изменения в доставке, задачах и секретах требуют соответствующих проверок. Не выполняй платные или внешние тесты на чужих аккаунтах.
