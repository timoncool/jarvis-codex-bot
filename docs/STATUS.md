# Статус публичного снимка

Дата подготовки: 2026-09-27. Исходники Python сверены с работающим локальным прототипом перед упаковкой. В публичной копии название, внутренние модули, переменные окружения, пути и сервисы переименованы в Jarvis. Действующая установка владельца отдельно получила новое отображаемое имя; её рабочие пути и данные не переносились.

## Проверки публичной копии

- Все **598 тестов** прошли на Python 3.14 в Linux после переименования модулей и настроек.
- Gitleaks 8.30.1: секретов не обнаружено. Проверка выполнялась с редактированием значений в отчёте.
- Тест журналирования требует полного скрытия URL с Telegram-токеном и отдельно проверяет отсутствие самого токена.

## Подтверждено в исходном прототипе

- Ответы официального Codex через Telegram.
- Генерация картинки и её доставка.
- Поиск через Sonar, вызываемый агентом через OpenRouter.
- Русская озвучка официальным SDK, конвертация PCM в OGG/Opus и доставка голосовым сообщением.
- Локальное распознавание голосового на faster-whisper large-v3/CUDA.
- Сохранение задачи и результата при аварийном завершении процесса, дедупликация и подтверждённая доставка.
- Скрытие технических статусов и корректная обработка `message is not modified`.

Кружки, аудио и видео направляются в общий обработчик речи; все кодеки отдельно не проверялись. Исторический короткий голосовой сценарий на Luna занял около 14 секунд; это не гарантия времени ответа.

## Изменения для публикации

- Чистый отбор исходников без рабочих данных и исторических установочных скриптов.
- Скилл сопровождения, пустой шаблон ключей, конфигурация Codex и systemd-сервисы.
- Отдельные CPU/CUDA-профили ASR; CPU-профиль — переносимая конфигурация, без отдельного замера качества и скорости на VPS.
- Русский README с предоставленным владельцем примером работы.

## Что не заявляется проверенным

Новый бот с отдельным токеном из публичной копии в рамках упаковки не запускался; рабочий бот не перезапускался. VPS с нуля не разворачивался. Полный цикл видеогенерации, все модели OpenRouter, все офисные форматы и абсолютная изоляция недоверенных пользователей не сертифицированы.

SDK предоставляет каталог дополнительных AI-операций. Возможность вызвать метод не равна проверке полного пользовательского сценария. Google, планировщик напоминаний, публикация сайтов и удалённый Windows отсутствуют.

Пакет предназначен для сопровождаемого развёртывания по SKILL.md. Он не должен рекламироваться как полностью проверенный универсальный установщик или готовая многопользовательская платформа без доработок.
